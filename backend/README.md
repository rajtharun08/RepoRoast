# RepoRoast Backend Service

The backend service is built asynchronously with FastAPI, LangChain, SlowAPI, and Supabase. It provides repository ingestion, context trimming, SSE token streaming, persona prompt generation, and quantitative performance scorecard calculation.

---

## Technical Architecture

```
backend/
├── app/
│   ├── api/
│   │   ├── auth.py          # User session sync with Supabase
│   │   ├── repo.py          # GitHub repository ingestion & level trimming
│   │   ├── interview.py     # SSE streaming, question management, hint/panic handlers
│   │   └── scorecard.py     # Evaluation scorecard generator
│   ├── core/
│   │   ├── config.py        # Environment variables & Pydantic settings
│   │   └── rate_limiter.py # SlowAPI rate limiter configuration
│   ├── services/
│   │   ├── github_service.py# GitHub API tree parser & level context scoping
│   │   ├── ai_service.py    # LangChain Gemini streaming engine
│   │   ├── persona_service.py # System prompts & interviewer personas
│   │   └── scorecard_service.py # Quantitative rating & feedback calculator
│   ├── db/
│   │   └── supabase_client.py # Supabase PostgreSQL database client
│   └── main.py              # FastAPI application initialization & CORS
├── tests/
│   ├── test_ai_engine.py    # Unit tests for AI service & persona prompts
│   ├── test_github_service.py # Unit tests for GitHub context trimming
│   └── test_api_endpoints.py  # End-to-end API route integration tests
└── requirements.txt
```

## API Reference

### 1. System Health & Info

#### `GET /`
- **Description**: Health check and application identification endpoint.
- **Rate Limit**: 30 requests/minute.
- **Response `200 OK`**:
  ```json
  {
    "status": "online",
    "app": "RepoRoast",
    "message": "Welcome to RepoRoast API Server"
  }
  ```

#### `GET /health`
- **Description**: Lightweight health probe for load balancers and containers.
- **Response `200 OK`**:
  ```json
  {
    "status": "healthy"
  }
  ```

---

### 2. Repository Ingestion

#### `POST /api/repo/ingest`
- **Description**: Parses a GitHub repository URL and retrieves a trimmed context window based on the difficulty escalation level.
- **Rate Limit**: 20 requests/minute.
- **Request Body**:
  ```json
  {
    "repo_url": "https://github.com/fastapi/fastapi",
    "level": 1
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "owner": "fastapi",
    "repo": "fastapi",
    "level": 1,
    "file_count": 2,
    "file_tree": ["README.md", "pyproject.toml"],
    "file_contents": {
      "README.md": "# FastAPI framework...",
      "pyproject.toml": "[tool.poetry.dependencies]..."
    }
  }
  ```

---

### 3. Interview Engine

#### `POST /api/interview/start`
- **Description**: Initializes a new 5-question mock interview session.
- **Rate Limit**: 15 requests/minute.
- **Request Body**:
  ```json
  {
    "repo_url": "https://github.com/fastapi/fastapi",
    "persona": "FAANG Gatekeeper",
    "custom_persona": "",
    "level": 1
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "session_id": "c9b8a1d2-3e4f-5a6b-7c8d-9e0f1a2b3c4d",
    "repo_url": "https://github.com/fastapi/fastapi",
    "persona": "FAANG Gatekeeper",
    "level": 1,
    "question_count": 1,
    "status": "in_progress"
  }
  ```

#### `GET /api/interview/stream/{session_id}`
- **Description**: Server-Sent Events (SSE) endpoint streaming real-time token responses generated by the LLM.
- **Query Parameters**: `answer` (optional string): Candidate answer to current question.
- **Media Type**: `text/event-stream`
- **SSE Stream Data Payload Format**:
  ```text
  data: {"text": "Welcome to your ", "question_count": 1, "status": "in_progress"}

  data: {"text": "technical screening...", "question_count": 1, "status": "in_progress"}
  ```

#### `POST /api/interview/answer`
- **Description**: Submits candidate's answer to the active question.
- **Rate Limit**: 30 requests/minute.
- **Request Body**:
  ```json
  {
    "session_id": "c9b8a1d2-3e4f-5a6b-7c8d-9e0f1a2b3c4d",
    "answer": "FastAPI leverages Pydantic for data validation and Starlette for web tooling."
  }
  ```

#### `POST /api/interview/hint/{session_id}`
- **Description**: Triggers a constructive hint and prompt pivot when the candidate is stuck.
- **Rate Limit**: 10 requests/minute.

#### `POST /api/interview/panic/{session_id}`
- **Description**: Triggers the Panic Button ("Reveal Answer"), forcing the AI to explain the optimal solution and advance to the next question.
- **Rate Limit**: 10 requests/minute.

### 4. Scorecard Engine

#### `GET /api/scorecard/{session_id}`
- **Description**: Generates and retrieves the post-interview evaluation report card upon completing all 5 questions.
- **Rate Limit**: 20 requests/minute.
- **Response `200 OK`**:
  ```json
  {
    "session_id": "c9b8a1d2-3e4f-5a6b-7c8d-9e0f1a2b3c4d",
    "repo_url": "https://github.com/fastapi/fastapi",
    "persona": "FAANG Gatekeeper",
    "level": 1,
    "overall_rating": 88.5,
    "breakdown": {
      "technical_depth": 85,
      "system_architecture": 90,
      "communication_clarity": 88,
      "problem_solving": 90,
      "code_quality": 89
    },
    "summary": "Completed 5-question technical interview evaluated by FAANG Gatekeeper persona at Level 1.",
    "strengths": [
      "Demonstrated strong understanding of framework design choices and dependencies."
    ],
    "areas_for_growth": [
      "Deepen knowledge of asynchronous resource cancellation edge cases."
    ],
    "panic_count": 0,
    "hint_count": 1,
    "total_questions": 5
  }
  ```

---

### 5. Auth & User Session

#### `POST /api/auth/session`
- **Description**: Syncs user profile metadata from GitHub OAuth into Supabase.
- **Rate Limit**: 15 requests/minute.
- **Request Body**:
  ```json
  {
    "github_id": "12345678",
    "username": "octocat",
    "email": "octocat@github.com",
    "avatar_url": "https://github.com/images/error/octocat_happy.gif"
  }
  ```

## Environment Variables

Create a `.env` file inside `backend/`:

```ini
PROJECT_NAME="RepoRoast"
API_V1_STR="/api"
SECRET_KEY="your-secret-key"

GEMINI_API_KEY="your-gemini-api-key"
GEMINI_MODEL="gemini-1.5-flash"

SUPABASE_URL="https://your-supabase-project.supabase.co"
SUPABASE_KEY="your-supabase-anon-key"
```
